# TechAssist AI

API REST desenvolvida com FastAPI para suporte e geração de Q&A contextual utilizando a API do Google Gemini.

##  Tecnologias Utilizadas

- **Python 3.12**
- **FastAPI**
- **Uvicorn**
- **Pydantic**
- **Google Generative AI SDK**
- **Python-Dotenv**
